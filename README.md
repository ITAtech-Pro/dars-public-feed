# DARS public realty feed

Публичный XML-фид ЖК «Живописный сад» для технической проверки сервиса
«Яндекс Поиск Недвижимости».

- Формат: XML, UTF-8
- Namespace: `http://webmaster.yandex.ru/schemas/feed/metarealty/2024-12`
- Файл: `dars-zhivopisnyysad-metarealty.xml`
- Назначение: техническая проверка интеграции

Канонический генератор и отчёт валидации хранятся в приватном Shared Workspace
в папке проекта `01 Clients/dars-development.ru/direct/realty-search-feed/`.

Не добавляйте в этот репозиторий внутренние документы клиента или агентства.
